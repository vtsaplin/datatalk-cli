# Spider Mechs — прототип

Браузерный прототип: шагающий паук-мех с процедурными IK-ногами, враги-боты, стрельба и
физические ящики на низкополигональном неоновом рельефе.

- Графика: [Three.js](https://threejs.org/) (+ UnrealBloom из `three/addons`)
- Физика: [cannon-es](https://github.com/pmndrs/cannon-es)
- Сборки нет: библиотеки грузятся с CDN через `importmap`, нужен только статический сервер.

## Запуск

```bash
cd spider-mechs
python3 -m http.server 8080
# открыть http://localhost:8080
```

(Подойдёт любой статический сервер: `npx serve`, `php -S`, Live Server в VS Code и т.п.
Открывать `index.html` как файл нельзя — ES-модули требуют http.)

## Управление

| Клавиша | Действие |
| --- | --- |
| Клик по экрану / Enter | старт |
| W / S | вперёд / назад |
| A / D, ← / → | поворот меха (камера едет за ним) |
| Q / E | шаг вбок |
| Мышь, ↑ / ↓ | поворот и наклон камеры (если мышь захватить нельзя, игра сама переходит на управление без захвата) |
| ЛКМ, F, Ctrl, Enter | огонь (лёгкий автоприцел по ближайшему врагу впереди) |
| Shift | бег |
| Space | прыжок |
| Esc | пауза |

Цель: уничтожить всех врагов (счётчик справа сверху), не потеряв броню.

## Как устроено

| Файл | Что делает |
| --- | --- |
| `src/spider.js` | Мех: физическая сфера парит над рельефом на пружине, шесть ног — процедурные: «домашние» точки едут с корпусом, стопа делает шаг, когда отстала, ноги шагают двумя тройками (tripod gait), колени ставит двухзвенная аналитическая IK. |
| `src/terrain.js` | FBM-шум → лоу-поли меш с покраской по высоте + `CANNON.Heightfield`; аналитический `heightAt()` для ног и hover. |
| `src/player.js` | Pointer lock, камера от третьего лица, стрельба по прицелу. |
| `src/enemy.js` | Конечный автомат бота: бродит → преследует → кружит и стреляет. |
| `src/projectiles.js` | Снаряды — физические сферы, урон по `collide`. |
| `src/props.js` | Ящики и валуны на физике. |
| `src/effects.js` | Bloom-композер и пул частиц. |
